## 📖 專案簡介 (Project Overview)

本專案為 **Ping-Kun Hsu (許鈵昆)** 的個人學術簡歷、研究範疇與軟體專案展示平台。採用當代高階科技美學的 **毛玻璃質感（Glassmorphism）** 與 **賽博極簡風格（Cyber-Minimalism）** 進行設計，具備流暢的雙向互動元件、雙模深淺外觀切換機制與全裝置響應式支援。

整體架構堅持 **Zero-Dependency（零外部重型框架依賴）**，純粹依託標準 **HTML5**、**Tailwind CSS** 與 **原生現代 JavaScript (ES6+)** 驅動，具備極致輕量、首屏秒開、易於維護與相容各類靜態代管（如 GitHub Pages）之優勢。

## ✨ 核心特色與亮點 (Key Features)

### 1. 🎨 賽博毛玻璃視覺體系 (Modern Cyber-Glassmorphism)
- **多層次磨砂質感**：利用 `backdrop-filter: blur(16px)` 與精緻漸層描邊，打造兼具未來感與通透度的卡片層次。
- **WCAG AA 高對比標準調優**：深淺雙色模式均經過色彩對比度校正，保證在明亮陽光或夜間暗室環境中皆具備極佳閱讀舒適性。
- **無縫微動態互動**：全站按鈕具備優雅的滑鼠 Hover 浮起（Elevation）、立體微投影與動態光澤反饋。

### 2. 🛡️ 沉浸式科技意象背景 (Ambient Tech Background)
頁面背景精心配置代表四大專業領域的 12 枚低干擾浮動科技圖示（Font Awesome 6），依章節克制點綴：
- ⚛️ **後量子密碼學 (PQC)**：量子物理象徵（`fa-atom`）、抗量子專用安全運算晶片（`fa-microchip`）。
- 🧊 **區塊鏈 (Blockchain)**：分散式帳本結構（`fa-cubes`）、智能合約去中心化鏈結（`fa-link`）。
- 🔑 **資訊安全 (Cybersecurity)**：密鑰安全協定（`fa-key`）、核心安全盾牌防禦（`fa-shield-halved`）、生物特徵識別（`fa-fingerprint`）、端點身分安全（`fa-user-shield`）。
- 🌐 **網路安全 (Network Security)**：網路拓撲協定（`fa-network-wired`）、惡意威脅阻絕（`fa-shield-virus`）、實機滲透攻防終端（`fa-terminal`）、安全雲端主機（`fa-server`）。
- **特有呼吸感浮動**：以 14s 至 18s 的極慢速雙向起伏交錯漂浮，置於底層並加上 `pointer-events-none`，絕不干擾前景閱讀與游標操作。

### 3. ⏱️ 互動式即時數位時鐘 (Live Interactive Clock Widget)
- **毫秒級即時時鐘**：流暢呈現當前時、分、秒，秒數獨立高光渲染搭配冒號律動閃爍。
- **12H / 24H 雙時制自由切換**：支援點擊即時變換時間格式，並自動透過 `localStorage` 記住使用者瀏覽偏好。
- **時區標示優化**：智慧標準化時區字串為符合直觀認知的 `時區：Etc/GMT+8`。
- **時間情境問候語**：依據早晨、中午、午後、傍晚與深夜自動切換暖心問候文案。
- **頁面停留計時器**：動態追蹤當前會話的停留時長（Session Duration Tracker）。

## 🚀 本機執行與快速開始 (Quick Start)

由於本專案為純前端無依賴架構，您無需安裝 Node.js、npm 或任何打包編譯工具即可直接預覽：

### 方法一：直接點擊開啟
使用任何現代瀏覽器（Google Chrome、Microsoft Edge、Firefox、Safari），直接連按兩下 `index.html` 檔案即可開始瀏覽。

### 方法二：使用 Python 內建 HTTP 伺服器
若您已安裝 Python，可開啟終端機（PowerShell / Terminal）並切換至本專案根目錄執行：
```bash
# Python 3
python -m http.server 8080
```
隨後在瀏覽器造訪：`http://localhost:8080`

### 方法三：使用 VS Code Live Server 擴充套件
1. 在 VS Code 中開啟專案資料夾。
2. 安裝套件 **Live Server** (by Ritwick Dey)。
3. 在 `index.html` 上按滑鼠右鍵，選擇 **"Open with Live Server"**。

## 🌐 部署至 GitHub Pages (Deployment)

本專案原生支援 GitHub Pages 零配置一鍵部署：

1. 將專案推送（Push）至您的 GitHub 儲存庫（Repository）。
2. 進入該 GitHub 專案頁面，點選右上角 **Settings**。
3. 在左側選單點選 **Pages**。
4. 在 **Build and deployment** 下方的 **Source** 選擇 **Deploy from a branch**。
5. 在 **Branch** 選單選擇 `main`（或 `master`），資料夾保持選擇 `/ (root)`，點擊 **Save**。
6. 等待約 1~2 分鐘，即可透過專屬網址造訪您的個人網頁：
   ```
   https://<your-github-username>.github.io/<repository-name>/
   ```
